DeepSeek Harness
正式版 · 全栈

dsh-native 把一台提升过的 DeepSeek Harness 完整打包：官方宿主版本锁定，四个内置插件随库分发， 三个社区插件按上游引用，科研版作为内置预设开箱即用。一条命令，复现整条栈。

快速开始 查看仓库

五层装配架构

不改动官方内核：dsh CLI 提供宿主运行时，profile 组合 bundle，插件以 cordis patch 注入界面， preset 以声明式 YAML 组装 agent，技能目录即插即用。每层可独立升级与替换。

L1 · Host

dsh CLI

官方 Harness 运行时，版本锁定 0.1.1-rc.2，保证复现一致。

L2 · Profile

web profile

profile/package.json 声明全部依赖与 bundle 组合，安装脚本合并写入本机。

    快速开始

    一条命令复现完整的全栈环境：CLI、七个插件、三个预设全部就位。

    1

    克隆仓库

    前置条件：Node.js 18+ 与 npm。

    git clone https://github.com/sjkncs/dsh-native.git
cd dsh-native
    2

    一键安装

    安装锁版本的 dsh CLI，把四个内置与三个社区插件写入 web profile 并注册 bundle，拷贝三个预设；设置文件缺失时写入模板。已装过 dsh 可加 --skip-dsh。

    node scripts/setup.mjs
    3

    启动

    浏览器访问本地服务；默认预设已是科研模式，也可在预设下拉里切换。

    dsh web   # http://127.0.0.1:3080
    4

    可选：桌面包装器

    Electron 窗口自启动 dsh web，关窗即清理整棵进程树，无孤儿进程。

    cd desktop && npm install && npm start

    仓库结构

    路径说明
    packages/四个内置插件 + 共享核心库：源码 + 构建产物 + cordis patch
    presets/三个预设：科研（默认）/ 建模编程 / 论文，随带技能目录
    profile/package.jsonweb profile 清单模板：依赖与 bundle 组合
    settings/settings.template.yaml设置模板（已脱敏，不含任何密钥）
    desktop/Electron 桌面包装器：自启动、就绪轮询、进程树清理
    scripts/setup.mjs跨平台一键安装脚本（Windows / macOS / Linux）
    site/本静态展示站，由 GitHub Pages 托管
