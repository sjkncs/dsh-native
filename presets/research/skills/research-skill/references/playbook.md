# 科研处境应对手册

按场景取用。原则不变：先摸底、讲证据、给动作，把取舍摆清楚。

## 选题被质疑"没创新"

1. 先把"创新点"拆开问：是新问题、新方法、新数据、还是新视角？四项占一项就能立住，别追求全占。
2. 让质疑方具体化："和哪几篇工作比、差在哪？"——泛泛说没创新多半是没说清差异。
3. 补差异的三板斧：换更强的基线重测、加一个对方没覆盖的设定/数据集、把方法动机讲成"解决他明确没解决的痛点"。
4. 真撞车了就大方承认，转"增量"叙事（更系统的评测、更好的可复现性、更低的成本）或者换道，别硬撑。

## 实验做不出预期结果

1. 先分清三类：实现错了（对拍官方/小规模复现）、设定不成立（数据/任务不匹配方法假设）、方法本身不行（前两者排除后才轮到）。
2. 留痕：每次只改一个变量，记全配置与种子；"我试过"没有日志等于没试过。
3. 阴性结果也是结果：分析"为什么不成立"本身就是贡献点，很多审稿人吃这一套。
4. 时间不够时的止损线：提前约定"再试 N 天/ N 组配置不行就换叙事或降档"，别让沉没成本拖死整个项目。

## 审稿意见怎么回

1. 逐条编号，先感谢再回应；语气平，不阴阳、不认怂过头。
2. 每条回应 = 审稿人关切是什么 → 我们做了什么（新增实验/修改/澄清）→ 改在哪（页码/行号）。
3. 不同意的意见不硬顶也不照单全收：给证据 + 给妥协方案（"已在 limitations 中说明，并补充了……实验"）。
4. 审稿人说"缺文献 X"——先核对该文献是否真实存在且相关，存在就引并说明差异；查无此文就客气地说明未检索到。
5. 大修最怕"只改不补"：能补的实验尽量补，补不了的把理由写成方法论限制，别留成下一轮的雷。

## 投稿：选刊选会与降档

1. 三问定位：工作的证据强度到哪一档？时间线卡不卡（会议截稿/毕业/结题）？目标读者在哪本刊物？
2. 冲稳保：一档冲目标、一档稳匹配、一档保底线，按拒稿周期排顺序，别同时投多处。
3. 降档不是失败：评审意见是免费的改进清单，改完再投命中率通常更高；但降级前先看范围合不合适，别投到读者不对的刊物。
4. cover letter 一段话讲清：问题是什么 → 我们的贡献 → 为什么适合这本刊物。不堆形容词。

## 时间不够 / 节奏崩了

1. 先列"最小可交付"：砍到只剩能自圆其说的核心实验 + 核心叙事，其他全部进 future work。
2. 按"发表层"倒排：截稿前 3 天必须冻结实验，只留写作与校对；最后一周还在补实验的项目基本要延期，早做决定。
3. 卡住超过两天没进展，就换粒度：把问题拆到半天能验证一个小假设的程度，用小胜利找回节奏。

## 导师 / 合作者意见冲突

1. 先把双方诉求翻译成同一层面：是目标冲突（发什么档）、方法冲突（怎么做）、还是优先级冲突（先做谁）？三种的解法完全不同。
2. 用证据说话：能跑对比实验的别吵，两天出个小规模对照；出不了的，把两个方案的成本和预期写成半页纸再谈。
3. 留痕但不较真：重要决定记进周会纪要/协作文档，出问题时对事不对人。

## 心态：被拒、被批评、比较焦虑

1. 拒稿信先看数据再看情绪：意见里能变成修改清单的才是有效信息，其余是噪声。
2. 被批评先分清"批评内容"和"批评方式"——内容对就收，方式差就过滤，两件事别搅在一起。
3. 比较焦虑多半是信息不对称：别人只晒成果不晒被拒。把注意力拉回自己的里程碑表，一步一结。
